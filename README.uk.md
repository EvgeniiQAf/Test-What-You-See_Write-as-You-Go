# Testmo AI Helper

Цей проєкт є допоміжним сервісом, розробленим для інтеграції з Testmo та використання можливостей штучного інтелекту, зокрема OpenAI, для допомоги у створенні та управлінні тест-кейсами.

## Системні вимоги

- [Node.js](https://nodejs.org/) (рекомендовано v18 або новішу)
- [npm](https://www.npmjs.com/) або [yarn](https://yarnpkg.com/)

## Встановлення

1.  **Склонуйте репозиторій:**
    ```bash
    git clone <url-вашого-репозиторію>
    cd testmo-ai-helper
    ```

2.  **Встановіть кореневі залежності:**
    Вони в основному потрібні для запуску тестів.
    ```bash
    npm install
    ```

3.  **Встановіть залежності сервера:**
    Перейдіть до директорії `server` та встановіть її залежності.
    ```bash
    cd server
    npm install
    ```

## Налаштування

Серверу потрібні змінні середовища для підключення до зовнішніх сервісів, таких як OpenAI та Testmo.

1.  **Створіть файл `.env`** у директорії `server/`, скопіювавши файл-приклад:
    ```bash
    cp .env.example .env
    ```
    *Примітка: Вам може знадобитися створити файл `.env.example` вручну, якщо його немає.*

2.  **Відредагуйте файл `.env`** та додайте ваші облікові дані:
    ```
    # Ключ API OpenAI
    OPENAI_API_KEY="ваш_ключ_api_openai"

    # Налаштування Testmo
    TESTMO_URL="https://yourcompany.testmo.net"
    TESTMO_TOKEN="ваш_токен_api_testmo"
    ```

## Запуск додатку

### Режим розробки

Щоб запустити сервер у режимі розробки з автоматичним перезавантаженням (завдяки `tsx`), виконайте наступну команду з директорії `server/`:

```bash
npm run dev
```

Сервер запуститься, зазвичай на порту 3000.

### Запуск тестів

Щоб запустити набір тестів, виконайте наступну команду з **кореневої** директорії:

```bash
npm test
```
