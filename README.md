# Test What You See

Turn exploratory testing into living documentation.

Most QA engineers start with documentation. But what if there isn't any?

With Test What You See, the product itself becomes the source of truth.

Simply explore the application, click on any UI element, and describe what you see directly on the screen. AI understands the selected element, its context, and your notes, then instantly generates structured documentation and test cases.

No switching between tools. No copy-paste. No writing everything from scratch.

Every observation can be reviewed and saved directly to your Test Management System.

## Workflow

1. Explore the product.
2. Select any UI element.
3. Describe what you see.
4. AI generates documentation and test cases.
5. Review the result.
6. Save directly to your TMS.

## Why?

- No documentation? Start testing immediately.
- Build documentation while exploring the product.
- Create consistent test cases with AI assistance.
- Keep documentation synchronized with the actual UI.
- Reduce manual work for QA teams.

Test what you see. Document as you explore. Save instantly.
